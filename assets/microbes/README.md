# Microbial Imagery Assets
This directory stores microscopic imagery for the 19 forensic bioindicator taxa in NecroTrace.

### How to add real images:
Save your real microscopy photo in this directory named after the taxon ID, using `.png`, `.jpg`, `.jpeg`, `.webp`, or `.svg`:
For example:
- `assets/microbes/Clostridium_perfringens.jpg`
- `assets/microbes/Staphylococcus_epidermidis.png`
- `assets/microbes/Proteus_mirabilis.png`

NecroTrace will automatically detect and render your real images in the diagnostic cards!
If no image file is found, it falls back to the clean geometric placeholder.
